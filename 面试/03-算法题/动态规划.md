# 动态规划

> **一句话定位**：动态规划不是「套公式」，而是**把一个大问题的答案，用小问题的答案拼出来**。想清楚「状态是什么、怎么转移」，代码只是三行循环。

返回 [算法题首页](README.md) · [面试首页](../README.md)。

## 识别信号

| 题面信号 | 该想的套路 | 状态设计方向 |
| --- | --- | --- |
| 求最大值 / 最小值 | 最值型 DP | `dp[i]` = 前 i 个元素的最优解 |
| 求方案总数 | 计数型 DP | `dp[i]` = 达到 i 的方案数，转移用加法 |
| 判断能不能达到 | 可行性 DP | `dp[i]` = 布尔值 |
| 两个字符串 / 两个序列 | 二维 DP | `dp[i][j]` = 前 i 个与前 j 个的关系 |
| 可以重复选取 | 完全背包 | 内层容量**正序**遍历 |
| 每个只能用一次 | 0-1 背包 | 内层容量**倒序**遍历 |
| 状态只依赖前一两项 | 滚动变量 | 用两个变量代替数组，空间 O(1) |

## 解题四步法

**这四步的顺序不能颠倒。** 面试时把它说出来，比直接写代码更能体现思路：

1. **定义状态**：`dp[i]` 或 `dp[i][j]` 到底代表什么？用一句话说出来，并且确保这句话里包含「前 i 个」或「以 i 结尾」这类限定词。
2. **写转移方程**：当前状态由哪些更小的状态推出来？这一步决定了正确性。
3. **确定初始化**：最小的状态（`dp[0]`、`dp[0][j]` 等）是什么？**边界初始化错了，整个表都是错的。**
4. **确定遍历顺序**：谁先谁后？一维要不要倒序？二维要不要压维？

## 核心辨析：两类背包的遍历顺序

这是动态规划最容易失分的地方，单独拿出来说：

| 问题类型 | 外层循环 | 内层循环 | 结果含义 |
| --- | --- | --- | --- |
| 0-1 背包 | 物品 | 容量**倒序** | 每件物品最多用一次 |
| 完全背包 | 物品 | 容量**正序** | 每件物品可用无限次 |
| 求**组合数** | 物品 | 容量 | `[1,2]` 和 `[2,1]` 视为同一种 |
| 求**排列数** | 容量 | 物品 | `[1,2]` 和 `[2,1]` 视为不同 |

**为什么 0-1 背包要倒序**：正序遍历时，`dp[i - weight]` 可能已经被本轮更新过，相当于同一件物品被用了多次。倒序保证每次取的是上一轮的值。

**为什么求排列数要把容量放外层**：外层是容量时，每个容量都会重新考虑所有物品，「先放 1 再放 2」和「先放 2 再放 1」会被分别计数。

## 典型题

### 题一：打家劫舍

**题干**：不能偷相邻的两家，求最大金额。

```java
public int rob(int[] nums) {
    int prev2 = 0;      // dp[i-2]：上上家的最优解
    int prev1 = 0;      // dp[i-1]：上一家的最优解
    for (int num : nums) {
        int cur = Math.max(prev1, prev2 + num);   // 不偷当前 vs 偷当前
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

- **时间 O(n)，空间 O(1)。**
- **状态定义**：`dp[i]` = 考虑前 i 家能偷到的最大金额。
- **转移方程**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。要么不偷第 i 家，要么偷它但不能偷第 i-1 家。
- **易错点**：初始值容易写错。这里用两个变量代替数组，`prev2` 和 `prev1` 都从 0 开始——含义是「还没有房子时金额为 0」，这样 `[2,7,9,3,1]` 的结果 12 才能正确算出。

### 题二：零钱兑换

**题干**：给定硬币面额数组和目标金额，求凑出金额所需的最少硬币数，凑不出返回 -1。

```java
public int coinChange(int[] coins, int amount) {
    int impossible = amount + 1;
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, impossible);        // 用「比任何合法答案都大」的值表示不可达
    dp[0] = 0;
    for (int coin : coins) {
        for (int i = coin; i <= amount; i++) {
            dp[i] = Math.min(dp[i], dp[i - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
```

- **时间 O(amount × coins.length)，空间 O(amount)。**
- **状态定义**：`dp[i]` = 凑出金额 i 所需的最少硬币数。
- **为什么用 `amount + 1` 当哨兵**：最少硬币数是 1 元硬币凑 `amount` 次，即最多 `amount` 枚。用 `amount + 1` 表示「不可能」，就避免了用 `Integer.MAX_VALUE` 时 `+1` 溢出的坑。
- **易错点**：判 `-1` 时比较的是 `dp[amount] > amount`，不是 `== impossible`。因为 `dp[amount]` 不一定会被更新成 `impossible`，用范围判断更稳。

### 题三：最长递增子序列

**题干**：求最长严格递增子序列的长度（子序列不要求连续）。

```java
public int lengthOfLIS(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    Arrays.fill(dp, 1);                 // 每个元素自身就是一个长度 1 的序列
    int best = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        best = Math.max(best, dp[i]);
    }
    return best;
}
```

- **时间 O(n²)，空间 O(n)。**
- **状态定义**：`dp[i]` = **以 `nums[i]` 结尾**的最长递增子序列长度。注意「以 i 结尾」这个限定词，它是转移成立的前提。
- **为什么答案不是 `dp[n-1]`**：最长序列可能不以最后一个元素结尾，所以要用 `best` 取全局最大。这是最经典的失分点。
- **优化方向**：维护一个「最小尾元素数组」，用二分查找把复杂度降到 O(n log n)。面试时可以先答 O(n²) 版本，再提优化方向。
- **易错点**：因为要「以 i 结尾」，所以必须**遍历所有 j < i**，不能只比较 `nums[i-1]`。

### 题四：最长公共子序列

**题干**：求两个字符串的最长公共子序列长度。

```java
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1] + 1;        // 字符相同，接上
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);   // 舍弃其中一个
            }
        }
    }
    return dp[m][n];
}
```

- **时间 O(mn)，空间 O(mn)。**
- **状态定义**：`dp[i][j]` = `text1` 前 i 个字符与 `text2` 前 j 个字符的最长公共子序列长度。
- **为什么下标从 1 开始**：`dp[0][j]` 和 `dp[i][0]` 表示「其中一个为空串」，结果为 0,天然初始化好了。取字符时用 `i - 1`、`j - 1`。
- **易错点**：`charAt` 的下标要减 1。这个 off-by-one 是二维 DP 最常见的 bug。

### 题五：编辑距离

**题干**：求把 `word1` 变成 `word2` 所需的最少操作数，允许插入、删除、替换。

```java
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) {
        dp[i][0] = i;                   // 删掉 word1 的前 i 个字符
    }
    for (int j = 0; j <= n; j++) {
        dp[0][j] = j;                   // 插入 j 个字符
    }
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = 1 + Math.min(
                        Math.min(dp[i - 1][j], dp[i][j - 1]),   // 删除 / 插入
                        dp[i - 1][j - 1]);                      // 替换
            }
        }
    }
    return dp[m][n];
}
```

- **时间 O(mn)，空间 O(mn)。**
- **状态定义**：`dp[i][j]` = 把 `word1` 前 i 个字符变成 `word2` 前 j 个字符的最少操作数。
- **三种转移的含义**：`dp[i-1][j]` 对应删除、`dp[i][j-1]` 对应插入、`dp[i-1][j-1]` 对应替换。**能说清每个下标变化对应哪种操作，才算真懂这道题。**
- **易错点**：字符相同时**不需要 +1**，直接用 `dp[i-1][j-1]`。写成 `1 + ...` 是常见错误。

## 易错点汇总

| 易错点 | 典型表现 | 预防 |
| --- | --- | --- |
| 状态定义含糊 | 转移方程推不出来 | 用一句话写出 `dp[i]` 的完整含义，含「前 i 个/以 i 结尾」 |
| 边界未初始化 | 结果整体偏移 | 先把第 0 行、第 0 列填完再进双层循环 |
| 背包遍历方向错 | 0-1 背包变成无限取 | 0-1 倒序、完全正序，写之前先确认 |
| 答案是 `dp[n-1]` | LIS 一类题取不到全局最优 | 非「以结尾定义」的题，答案往往要取全局 max |
| 二维下标 off-by-one | 数组越界或结果错 | 统一用「前 i 个」语义，取字符时 `i-1` |
| 用 MAX_VALUE 做哨兵 | 加一溢出成负数 | 用问题规模上界 + 1 作为哨兵 |
