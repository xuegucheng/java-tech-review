# 二叉树

> **一句话定位**：二叉树题的 90% 都能用「递归三要素」解决——**先想清楚这个节点要做什么、什么时候停、返回值给谁**。想不清这三件事，就会写出「能跑但自己看不懂」的代码。

返回 [算法题首页](README.md) · [面试首页](../README.md)。

## 基础节点定义

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode(int val) {
        this.val = val;
    }
}
```

## 识别信号

| 题面信号 | 该想的套路 | 为什么 |
| --- | --- | --- |
| 求深度、路径、判断性质 | 后序递归（左右子树结果汇总） | 需要子树的信息才能算当前节点 |
| 按层、每层一行、最短路径 | BFS + 队列 | 层序天然对应队列的先进先出 |
| BST 相关（查找、第 k 小、验证） | 中序遍历有序 | BST 的中序序列是升序的 |
| 找祖先、分叉点 | 后序递归 + 分情况返回 | 需要知道目标节点在左还是右 |
| 构造树（前序+中序） | 分治 + 定位根节点 | 前序定根，中序分左右 |
| 求「经过根的最大值」类 | 递归中维护全局最优 | 路径可以不返回给父节点 |

## 核心模板

### 模板一：递归三要素

```java
public 返回类型 traverse(TreeNode root) {
    // ① 终止条件：空节点返回什么？
    if (root == null) {
        return 空值;
    }
    // ② 处理左右子树：拿到子问题的解
    左结果 = traverse(root.left);
    右结果 = traverse(root.right);
    // ③ 合并并返回给父节点：当前子树的答案是什么？
    return 合并(左结果, 右结果, root);
}
```

**关键判断**：返回值是「给父节点的答案」还是「当前子树的最优解」。像二叉树最大路径和，**返回给父节点的路径只能在左右里选一条**（不能拐弯），但全局最优可以左右都算（可以拐弯）。这个区分是二叉树题最常见的失分点。

### 模板二：层序遍历 BFS

```java
Deque<TreeNode> queue = new ArrayDeque<>();
queue.offer(root);
while (!queue.isEmpty()) {
    int size = queue.size();        // 必须先固定，否则循环中 size 会变
    for (int i = 0; i < size; i++) {
        TreeNode node = queue.poll();
        // 处理 node
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
    }
}
```

## 典型题

### 题一：二叉树的层序遍历

**题干**：按层返回所有节点的值。

```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) {
        return res;
    }
    Deque<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>(size);
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) {
                queue.offer(node.left);
            }
            if (node.right != null) {
                queue.offer(node.right);
            }
        }
        res.add(level);
    }
    return res;
}
```

- **时间 O(n)，空间 O(w)（w 为最大层宽）。**
- **易错点**：`int size = queue.size()` 必须写在 `for` 循环外。如果写成 `for (int i = 0; i < queue.size(); i++)`，循环中入队的新节点会让条件持续变化，结果层序全乱。
- **面试变体**：锯齿形层序遍历 → 偶数层反转 `level`；右视图 → 每层只取最后一个。

### 题二：二叉树的最近公共祖先

**题干**：给定两个节点，返回它们的最近公共祖先。

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) {
        return root;
    }
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) {
        return root;                        // 左右各找到一个，当前节点即分叉点
    }
    return (left != null) ? left : right;   // 都在同一侧，把找到的那个往上传递
}
```

- **时间 O(n)，空间 O(h)（h 为树高，即递归栈深度）。**
- **关键点**：`root == p || root == q` 时直接返回 `root`。这个「找到了就上报」的策略，让结果自然向上冒泡。
- **易错点**：不要试图去比较「路径数组」。用后序递归的分情况判断，代码只有 8 行。
- **面试变体**：如果是二叉搜索树，可以利用大小关系提前剪枝，O(h) 即可完成——从根开始，两值都小走左边，都大走右边，否则当前即答案。

### 题三：验证二叉搜索树

**题干**：判断一棵树是否为合法 BST。

```java
public boolean isValidBST(TreeNode root) {
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

private boolean validate(TreeNode node, long low, long high) {
    if (node == null) {
        return true;
    }
    if (node.val <= low || node.val >= high) {
        return false;
    }
    return validate(node.left, low, node.val)
            && validate(node.right, node.val, high);
}
```

- **时间 O(n)，空间 O(h)。**
- **为什么不用 `Integer.MIN_VALUE` 当哨兵**：节点值本身可能就是 `Integer.MIN_VALUE`，用 `int` 做上下界会误判。用 `long` 或 `null` 表示无界。
- **最常见的错误答法**：只比较 `node.val > node.left.val && node.val < node.right.val`。这是**局部判断**，会漏掉「右子树的左孙节点仍然必须大于根节点」这类跨层约束。正确的做法是**把上下界一路传下去**。
- **等价写法**：中序遍历，检查序列是否严格递增。面试时两种都可以，**主动说出「我知道还有中序写法」是加分项**。

### 题四：二叉树的最大深度与直径

**题干**：最大深度是根到最远叶子的节点数；直是任意两节点间最长路径的边数。

```java
public int maxDepth(TreeNode root) {
    if (root == null) {
        return 0;
    }
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}
```

```java
private int diameter;

public int diameterOfBinaryTree(TreeNode root) {
    diameter = 0;               // 多次调用前重置，避免状态残留
    depth(root);
    return diameter;
}

private int depth(TreeNode node) {
    if (node == null) {
        return 0;
    }
    int left = depth(node.left);
    int right = depth(node.right);
    diameter = Math.max(diameter, left + right);    // 以当前节点为顶点的最长路径
    return 1 + Math.max(left, right);               // 返回给父节点：只能走一边
}
```

- **时间复杂度均为 O(n)。**
- **关键区分**：`depth` **返回给父节点**的是单边最长（因为路径不能分叉），而**更新全局答案**时用的是 `left + right`（因为直径可以在当前节点拐弯）。这两行的差别就是这道题的全部考点。
- **易错点**：把 `diameter` 写成局部变量。它必须在递归过程中持续更新，所以要么用实例字段，要么用长度为 1 的数组。

## 易错点汇总

| 易错点 | 典型表现 | 预防 |
| --- | --- | --- |
| 返回值语义混淆 | 路径类题目答案偏小 | 明确区分「返回给父节点」和「全局最优」 |
| 层序 size 未固定 | 层的划分错乱 | `size` 先取出来再进循环 |
| BST 只做局部比较 | 跨层约束漏判 | 传上下界，或改用中序递增检查 |
| 空节点处理遗漏 | 空指针异常 | 递归第一行永远是 `if (root == null)` |
| 全局状态未重置 | 多次调用结果累加 | 每次调用前重置字段 |
| 用 `int` 做哨兵 | 边界值误判 | 用 `long` 或 `null` 表示无界 |
