# 链表

> **一句话定位**：链表题不难在思路，难在**指针别丢、边界别越**。虚拟头节点能一次性消掉绝大多数「头节点要特殊处理」的分支。

返回 [算法题首页](README.md) · [面试首页](../README.md)。

## 基础节点定义

以下所有解法都基于这个定义：

```java
class ListNode {
    int val;
    ListNode next;

    ListNode(int val) {
        this.val = val;
    }
}
```

## 识别信号

| 题面信号 | 该想的套路 | 为什么 |
| --- | --- | --- |
| 可能要删/改头节点 | 虚拟头节点（dummy） | 让头节点和其他节点走同一套逻辑 |
| 找倒数第 k 个、找中点 | 快慢指针 | 让快指针先走 k 步制造距离差 |
| 判断有环、找环入口 | 快慢指针 | 相遇点与入口点存在确定的数量关系 |
| 反转、部分反转 | 三指针滚动 | 需要同时记住前驱和后继 |
| 合并、拆分 | 虚拟头节点 + 尾指针 | 尾指针维护「已合并区」的末尾 |
| 找相交点 | 双指针等长 | 让两条链的剩余长度相等 |

## 核心模板

### 模板一：虚拟头节点

```java
ListNode dummy = new ListNode(0);
dummy.next = head;
ListNode prev = dummy;          // prev 始终指向「已处理区」的最后一个节点

// ... 处理逻辑，通过 prev.next 增删节点

return dummy.next;              // 真实头节点可能已经变了
```

**为什么有效**：删除头节点的场景需要「把新头节点返回给调用方」。有 dummy 后，头节点也有了前驱，代码里不再出现 `if (head 要删除) ... else ...` 这种分支。

### 模板二：反转链表的三指针滚动

```java
ListNode prev = null;
ListNode cur = head;
while (cur != null) {
    ListNode next = cur.next;   // ① 先存后继，否则翻转后找不到
    cur.next = prev;            // ② 翻转指针
    prev = cur;                 // ③ prev 前移
    cur = next;                 // ④ cur 前移
}
return prev;
```

**四步顺序不能乱**：必须在改 `cur.next` 之前把 `next` 存下来，这是链表反转最常见的失分点。

## 典型题

### 题一：反转链表

**题干**：反转一个单链表。

```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode cur = head;
    while (cur != null) {
        ListNode next = cur.next;
        cur.next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}
```

- **时间 O(n)，空间 O(1)。**
- **易错点**：返回 `prev` 而不是 `cur`。循环结束时 `cur` 已经是 `null`，`prev` 才是新的头节点。
- **递归写法**（面试可提，但不建议当主答案）：

```java
public ListNode reverseListRecursive(ListNode head) {
    if (head == null || head.next == null) {
        return head;
    }
    ListNode newHead = reverseListRecursive(head.next);
    head.next.next = head;      // 让后继反过来指向自己
    head.next = null;           // 断开原来的正向指针，否则形成环
    return newHead;
}
```

递归的空间复杂度是 O(n)（栈深度）。**面试时如果写了递归，一定要主动说「空间是 O(n)，迭代版本是 O(1)，要不要我改写迭代的」。**

### 题二：环形链表 II

**题干**：如果链表有环，返回入环的第一个节点；无环返回 `null`。要求空间 O(1)。

```java
public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            ListNode p = head;              // 相遇后，一个从头走
            while (p != slow) {
                p = p.next;
                slow = slow.next;           // 另一个从相遇点走
            }
            return p;
        }
    }
    return null;
}
```

- **时间 O(n)，空间 O(1)。**
- **原理**：设头到入口距离 `a`，入口到相遇点距离 `b`，相遇点绕回入口距离 `c`。相遇时慢指针走了 `a+b`，快指针走了 `a+b+c+b`，且快指针路程是慢指针的两倍，可得 `a = c`。所以从头和从相遇点同时出发，必然在入口相遇。
- **易错点**：循环条件是 `fast != null && fast.next != null`，两个都要判。少判 `fast.next` 会在偶数长度链表上抛空指针。
- **复杂度追问**：「为什么快指针每次走两步不是三步？」步长 2 时两者距离每次缩小 1，一定相遇；步长 3 可能跨过相遇点，需要额外条件才能保证。

### 题三：合并两个有序链表

**题干**：合并两个升序链表，返回合并后的升序链表。

```java
public ListNode mergeTwoLists(ListNode a, ListNode b) {
    ListNode dummy = new ListNode(0);
    ListNode tail = dummy;
    while (a != null && b != null) {
        if (a.val <= b.val) {
            tail.next = a;
            a = a.next;
        } else {
            tail.next = b;
            b = b.next;
        }
        tail = tail.next;
    }
    tail.next = (a != null) ? a : b;    // 剩余部分直接接上，无需逐个复制
    return dummy.next;
}
```

- **时间 O(m+n)，空间 O(1)。**
- **关键点**：剩余部分**直接接上**。写成 `while (a != null) { tail.next = new ListNode(a.val); ... }` 是常见错误——多花了空间，也暴露没理解链表是引用结构。
- **易错点**：`<=` 保证稳定性（相等时优先取 a）。如果题目要求稳定合并，这里必须用 `<=`。

### 题四：删除链表的倒数第 N 个节点

**题干**：删除倒数第 n 个节点，返回头节点，要求一次遍历。

```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode fast = dummy, slow = dummy;
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }
    while (fast.next != null) {
        fast = fast.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;
    return dummy.next;
}
```

- **时间 O(n)，空间 O(1)。**
- **关键点**：`slow` 从 `dummy` 出发而不是 `head`，这样停止时 `slow` 正好落在**待删除节点的前驱**上。
- **易错点**：删除头节点（`n == 链表长度`）时，如果没有 dummy，`slow` 会落在 `null` 上无法操作。dummy 直接解决这个问题。

### 题五：K 个一组翻转链表（高阶）

**题干**：每 k 个节点一组翻转，剩余不足 k 个保持原样。

```java
public ListNode reverseKGroup(ListNode head, int k) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode groupPrev = dummy;

    while (true) {
        ListNode kth = groupPrev;
        for (int i = 0; i < k && kth != null; i++) {
            kth = kth.next;
        }
        if (kth == null) {
            break;                          // 剩余不足 k 个
        }
        ListNode groupNext = kth.next;
        ListNode prev = groupNext;          // 让反转后的组尾直接指向下一组
        ListNode cur = groupPrev.next;
        while (cur != groupNext) {
            ListNode next = cur.next;
            cur.next = prev;
            prev = cur;
            cur = next;
        }
        ListNode newGroupHead = prev;
        ListNode oldGroupHead = groupPrev.next;
        groupPrev.next = newGroupHead;      // 前驱接上新的组头
        groupPrev = oldGroupHead;           // 原组头反转后成了组尾
    }
    return dummy.next;
}
```

- **时间 O(n)（每个节点只被翻一次），空间 O(1)。**
- **关键点一**：先探测够不够 k 个，不够就 `break`，避免处理尾部的残缺组。
- **关键点二**：`prev` 初始化为 `groupNext` 而不是 `null`，这样反转完成后组尾自动指向下一组，省掉一次额外接线。
- **关键点三**：`groupPrev = oldGroupHead`——**反转前**的原组头，**反转后**就是组尾，正好是下一组的前驱。
- **易错点**：`cur != groupNext` 这个终止条件容易写成 `cur != null`，那样会把后面的组也一起翻掉。

## 易错点汇总

| 易错点 | 典型表现 | 预防 |
| --- | --- | --- |
| 翻转前没存后继 | 空指针或断链 | 记住四步顺序：存 next → 翻指针 → 前移 prev → 前移 cur |
| 头节点特殊处理 | 删除/合并时漏分支 | 一律用 dummy |
| 返回值选错 | 返回 null 或旧头 | 想清楚循环结束时每个指针停在哪 |
| 循环条件漏判 | `fast.next` 触发空指针 | 只要访问 `node.next.next`，就同时判 `node` 和 `node.next` |
| 环的判断忘记断链 | 链表自身成环，输出死循环 | 反转/拆分后主动检查是否还有环 |
