# 回溯与图搜索

> **一句话定位**：回溯 = **在决策树上做 DFS，走过就撤销**；图搜索 = **在状态图上做 DFS/BFS，走过就标记**。两者的骨架几乎一样，区别只在「撤销」还是「标记」。

返回 [算法题首页](README.md) · [面试首页](../README.md)。

## 识别信号

| 题面信号 | 该想的套路 | 关键动作 |
| --- | --- | --- |
| 求「所有」排列 / 组合 / 子集 | 回溯 | 记录路径 + 撤销选择 |
| 求「所有」合法方案（括号、N 皇后） | 回溯 + 剪枝 | 提前判断当前路径是否还可能合法 |
| 网格连通块、区域填充 | 网格 DFS/BFS | 原地标记，避免重复访问 |
| 最短路径（无权图） | BFS | 队列天然按层扩展 |
| 依赖关系、能否完成 | 拓扑排序 | 入度为零入队，能全部出队则无环 |
| 从一个起点扩散到多个终点 | 多源 BFS | 所有起点先入队 |

## 核心模板

### 模板一：回溯三要素

```java
void backtrack(状态参数, 路径 path, 结果集 res) {
    if (到达决策树叶子) {
        res.add(new 集合(path));      // ① 必须拷贝，否则加入的是同一个引用
        return;
    }
    for (选择 : 当前可选集合) {
        if (剪枝条件) continue;        // ② 剪枝可以放在这里，也可以放在更早
        path.add(选择);                // ③ 做选择
        backtrack(新状态, path, res);  // ④ 递归
        path.remove(最后一步);          // ⑤ 撤销选择（与 ③ 严格配对）
    }
}
```

**三要素**：路径（已做的选择）、选择列表（当前能做的选择）、结束条件。

### 模板二：排列与组合的写法差异

这是回溯题最容易混的地方，单独说清楚：

| 问题类型 | 循环起点 | 是否需要 `used` 数组 | 为什么 |
| --- | --- | --- | --- |
| 排列（全排列） | `i = 0` | 需要 | 每次都从全部元素里挑，但要跳过已用的 |
| 组合 / 子集 | `i = start` | 不需要 | 只往后挑，天然去重 |
| 含重复元素只需去重组合 | `i = start` | 不需要 | 加 `if (i > start && nums[i] == nums[i-1]) continue;` |

**记忆方式**：排列要「顺序」，所以得记住谁用过；组合只要「集合」，所以用起点限制方向就够了。

## 典型题

### 题一：全排列

**题干**：返回数组的所有全排列。

```java
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    backtrackPermute(nums, new boolean[nums.length], new ArrayList<>(), res);
    return res;
}

private void backtrackPermute(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == nums.length) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) {
            continue;
        }
        used[i] = true;
        path.add(nums[i]);
        backtrackPermute(nums, used, path, res);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
```

- **时间 O(n × n!)，空间 O(n)。**
- **为什么是 n × n!**：共 n! 个排列，每个排列要花 O(n) 拷贝到结果集。
- **易错点一**：`res.add(new ArrayList<>(path))` 必须新建。写成 `res.add(path)` 会得到一堆指向同一个空列表的引用。
- **易错点二**：`used[i] = false` 的撤销不能漏。漏了会导致后续分支少元素。

### 题二：子集

**题干**：返回数组的所有子集。

```java
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    backtrackSubsets(nums, 0, new ArrayList<>(), res);
    return res;
}

private void backtrackSubsets(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path));      // 每个节点都是一个合法子集，不需要等叶子
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        backtrackSubsets(nums, i + 1, path, res);   // 注意是 i + 1，保证不重复取
        path.remove(path.size() - 1);
    }
}
```

- **时间 O(n × 2ⁿ)，空间 O(n)。**
- **与排列的关键区别**：结果收集在**每个节点**而非叶子；循环从 `start` 开始而非 0。
- **易错点**：递归调用传 `i + 1` 而不是 `start + 1`。传 `start + 1` 会导致元素重复使用。

### 题三：括号生成

**题干**：生成 n 对括号的所有合法组合。

```java
public List<String> generateParenthesis(int n) {
    List<String> res = new ArrayList<>();
    backtrackParenthesis(n, 0, 0, new StringBuilder(), res);
    return res;
}

private void backtrackParenthesis(int n, int open, int close, StringBuilder path, List<String> res) {
    if (path.length() == 2 * n) {
        res.add(path.toString());
        return;
    }
    if (open < n) {
        path.append('(');
        backtrackParenthesis(n, open + 1, close, path, res);
        path.deleteCharAt(path.length() - 1);
    }
    if (close < open) {                  // 剪枝：右括号数量不能超过左括号
        path.append(')');
        backtrackParenthesis(n, open, close + 1, path, res);
        path.deleteCharAt(path.length() - 1);
    }
}
```

- **时间 O(Catalan(n))，空间 O(n)。**
- **剪枝的本质**：`close < open` 保证任意前缀中左括号不少于右括号，直接排除了非法路径，比「生成所有组合再校验」高效得多。
- **易错点**：`if (open < n)` 和 `if (close < open)` 是两个独立分支，不是二选一。写 `else if` 会漏方案。

### 题四：岛屿数量

**题干**：`'1'` 为陆地，`'0'` 为水，求岛屿数量（上下左右相连算同一块）。

```java
public int numIslands(char[][] grid) {
    if (grid == null || grid.length == 0) {
        return 0;
    }
    int count = 0;
    for (int i = 0; i < grid.length; i++) {
        for (int j = 0; j < grid[0].length; j++) {
            if (grid[i][j] == '1') {
                count++;
                sink(grid, i, j);
            }
        }
    }
    return count;
}

private void sink(char[][] grid, int i, int j) {
    if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length || grid[i][j] != '1') {
        return;
    }
    grid[i][j] = '0';                    // 原地标记，省掉 visited 数组
    sink(grid, i + 1, j);
    sink(grid, i - 1, j);
    sink(grid, i, j + 1);
    sink(grid, i, j - 1);
}
```

- **时间 O(mn)（每个格子最多访问一次），空间 O(mn)（最坏为全部陆地时的递归深度）。**
- **关键点**：越界判断和访问判断**合并写在递归的第一行**，这样主循环里只需要判断 `== '1'`，代码最简。
- **易错点**：`grid[0].length` 在 `grid` 为空时会抛异常，所以先判 `grid.length == 0`。
- **面试变体**：网格很大导致递归栈溢出时，改用 BFS + 队列（把 `sink` 换成显式队列即可，避免深递归）。

### 题五：课程表

**题干**：`prerequisites[i] = [a, b]` 表示学 a 前必须先学 b。判断能否完成所有课程（等价于判断有向图是否有环）。

```java
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> graph = new ArrayList<>(numCourses);
    for (int i = 0; i < numCourses; i++) {
        graph.add(new ArrayList<>());
    }
    int[] inDegree = new int[numCourses];
    for (int[] p : prerequisites) {
        graph.get(p[1]).add(p[0]);       // 边方向：先修课 -> 后续课
        inDegree[p[0]]++;
    }
    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < numCourses; i++) {
        if (inDegree[i] == 0) {
            queue.offer(i);              // 入度为 0 的课程可以立刻学
        }
    }
    int finished = 0;
    while (!queue.isEmpty()) {
        int course = queue.poll();
        finished++;
        for (int next : graph.get(course)) {
            if (--inDegree[next] == 0) {
                queue.offer(next);
            }
        }
    }
    return finished == numCourses;       // 有环时必然有课程永远无法入队
}
```

- **时间 O(V + E)，空间 O(V + E)。**
- **为什么能判环**：环上的节点入度永远不会降到 0，所以它们永远进不了队列。最终 `finished < numCourses` 就说明有环。
- **易错点一**：边的方向别搞反。`[a, b]` 是「b → a」，因为 b 是前置。
- **易错点二**：`--inDegree[next] == 0` 是先减再比，别写成 `inDegree[next]-- == 0`。
- **面试变体**：要求返回学习顺序 → 把 `poll` 出来的节点依次收集进结果数组即可。

## 易错点汇总

| 易错点 | 典型表现 | 预防 |
| --- | --- | --- |
| 结果集未拷贝 | 结果全是空列表 | `res.add(new ArrayList<>(path))` |
| 撤销不配对 | 结果多方案或缺方案 | 做选择和撤销必须紧邻递归两侧 |
| 排列组合混淆 | 结果重复或缺失 | 排列用 `used` + 从 0 循环；组合用 `start` |
| 重复元素未剪枝 | 结果有重复 | 排序 + `i > start && nums[i] == nums[i-1]` |
| 网格越界未判 | 数组越界异常 | 越界和访问判断写在递归第一行 |
| 边的方向写反 | 拓扑排序结果全错 | 先写出「谁指向谁」再写代码 |
| 深递归栈溢出 | 大网格崩溃 | 换 BFS |
