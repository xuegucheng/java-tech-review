# 数组与双指针

> **一句话定位**：数组题的暴力解通常是 O(n²)，而绝大多数能降到 O(n) 的解法，本质都是**让两个指针各自只往一个方向走**。

返回 [算法题首页](README.md) · [面试首页](../README.md)。

## 识别信号

| 题面信号 | 该想的套路 | 为什么 |
| --- | --- | --- |
| 数组有序，找两个数/三个数 | 对撞指针 | 有序性可以让你排除一整个区间 |
| 原地删除、原地移动 | 快慢指针 | 慢指针维护「已处理区」的边界 |
| 连续子数组、最长/最短子串 | 滑动窗口 | 窗口边界单调移动，均摊 O(n) |
| 求面积、容量、最大值 | 对撞指针 + 贪心 | 两侧中较矮的一侧移动才可能变优 |
| 需要「找某值是否存在」 | 哈希表 | 空间换时间 |
| 求和为定值、区间和 | 前缀和 | 把区间和降为 O(1) 查询 |

## 核心模板

### 模板一：对撞指针

适用于有序数组中的配对、求和问题。**关键是每次移动都能确定性地排除掉不可能的解。**

```java
int left = 0, right = n - 1;
while (left < right) {
    // 根据 nums[left] 与 nums[right] 的关系决定移动哪一边
    if (满足条件) {
        return 结果;
    } else if (偏小) {
        left++;      // 只能靠增大左侧来变大
    } else {
        right--;     // 只能靠减小右侧来变小
    }
}
```

### 模板二：快慢指针（原地修改）

适用于原地删除、去重、移动元素。**慢指针的含义是「下一个待写入位置」，不变式是 slow 之前都已处理完。**

```java
int slow = 0;
for (int fast = 0; fast < n; fast++) {
    if (保留 nums[fast] 的条件) {
        nums[slow++] = nums[fast];   // 需要保留则写入
    }
}
// slow 即为处理后的长度
```

### 模板三：滑动窗口

适用于「连续子数组/子串」的极值问题。**窗口右边界只增不减，左边界按条件收缩，总移动次数是 O(n)。**

```java
int left = 0;
for (int right = 0; right < n; right++) {
    加入 nums[right];                 // 扩张
    while (需要收缩的条件) {
        移出 nums[left];              // 收缩
        left++;
    }
    更新答案;
}
```

## 典型题

### 题一：两数之和

**题干**：给定整数数组和目标值，返回两个数的下标，使其和等于目标值。假设只有一个答案，且同一元素不能重复使用。

```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> seen = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (seen.containsKey(need)) {
            return new int[]{seen.get(need), i};
        }
        seen.put(nums[i], i);
    }
    return new int[0];
}
```

- **时间 O(n)，空间 O(n)。**
- **关键点**：判断在放入之前做，自然保证了不用同一个元素两次。
- **面试变体**：如果要求**不能用额外空间**且数组已排序，改用对撞指针，O(1) 空间但会丢失原始下标。
- **易错点**：先 `put` 再判断，会把当前元素和自己配对（当 `target = 2 * nums[i]` 时会返回同一个下标两次）。

### 题二：三数之和

**题干**：找出所有和为 0 且不重复的三元组。

```java
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> res = new ArrayList<>();
    int n = nums.length;
    for (int i = 0; i < n - 2; i++) {
        if (nums[i] > 0) {
            break;                                   // 最小的数已大于 0，后面不可能凑成 0
        }
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;                                // 跳过重复的第一个数
        }
        int left = i + 1, right = n - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left + 1]) {
                    left++;                          // 跳过重复的第二个数
                }
                while (left < right && nums[right] == nums[right - 1]) {
                    right--;                         // 跳过重复的第三个数
                }
                left++;
                right--;
            } else if (sum < 0) {
                left++;                              // 和偏小，增大左侧
            } else {
                right--;                             // 和偏大，减小右侧
            }
        }
    }
    return res;
}
```

- **时间 O(n²)（外层 O(n)，内层对撞 O(n)），空间 O(log n)（排序栈深度）。**
- **先排序的意义**：既让对撞指针成立，也让「跳过重复」变得简单——重复元素一定相邻。
- **易错点**：三处去重缺一不可。漏掉外层去重会得到重复的三元组；漏掉内层去重会在 `[0,0,0,0]` 这类输入上重复。
- **复杂度追问**：「为什么不是 O(n log n)？」排序是 O(n log n)，但外层循环没法省——固定第一个数之后才轮到双指针。

### 题三：无重复字符的最长子串

**题干**：给定字符串，找出不含重复字符的最长子串的长度。

```java
public int lengthOfLongestSubstring(String s) {
    int[] lastIndex = new int[128];          // 假设为 ASCII，用数组代替哈希表更快
    Arrays.fill(lastIndex, -1);
    int left = 0, best = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (lastIndex[c] >= left) {
            left = lastIndex[c] + 1;         // 窗口内出现重复，左边界跳到上次出现的下一位
        }
        lastIndex[c] = right;
        best = Math.max(best, right - left + 1);
    }
    return best;
}
```

- **时间 O(n)，空间 O(1)（字符集大小固定为 128）。**
- **关键点**：`left` 只前进不后退。写 `left = lastIndex[c] + 1` 而不是 `left++`，才能一次跳到位。
- **易错点**：必须判断 `lastIndex[c] >= left`。如果上次出现的位置在窗口外，那不算重复，不能移动左边界。
- **面试变体**：改成「最多包含 k 个不同字符」→ 窗口内用哈希计数，超出 k 时收缩左边。

### 题四：移动零

**题干**：将所有 0 移到数组末尾，同时保持非零元素的相对顺序，要求原地操作。

```java
public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            int tmp = nums[slow];
            nums[slow] = nums[fast];
            nums[fast] = tmp;
            slow++;
        }
    }
}
```

- **时间 O(n)，空间 O(1)。**
- **关键点**：交换而不是覆盖，保证即使是 `[1]`、`[]`、`[0,0,1]` 这类输入也正确。
- **易错点**：如果写成「非零往前覆盖，末尾补零」，在 `[0,1,0,3]` 上会覆盖掉尚未访问的元素——必须先读完再补零，或者直接用交换。

## 易错点汇总

| 易错点 | 典型表现 | 预防 |
| --- | --- | --- |
| 指针移动条件写反 | 结果偏移一位或死循环 | 先在手写例子（3 个元素）上推一遍 |
| 去重漏一处 | 结果有重复三元组 | 三数之和固定「外层 + 两个内层」三处检查 |
| 边界未覆盖 | 空数组、单元素、全零 | 写完立刻口头过一遍这四种输入 |
| 窗口左边界回退 | 复杂度退化到 O(n²) | 确认 `left` 单调不减 |
| 溢出 | 大数相加、乘积比较 | 用 `long` 或先除后乘 |
