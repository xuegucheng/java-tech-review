## 先看这个：面试轮次的通用节奏

不同公司的轮次名称不一样，但**每一轮在考什么是相对稳定的**。同样一道「说一下 HashMap」，一面和终面想要的答案长度完全不同。先建立这张地图，再决定每道题该答多深。

| 轮次 | 主要考察 | 典型的问法形态 | 回答时长预期 |
| --- | --- | --- | --- |
| 一面（基础面） | Java 基础、集合、并发、网络、数据库基础 | 覆盖面广、单题浅，一问一答快节奏 | 单题 1～3 分钟 |
| 二面（技术面） | 项目深挖、场景设计、方案取舍 | 从你的项目出发，层层追问「为什么」 | 单题 5～15 分钟 |
| 三面（主管/交叉面） | 系统设计、架构判断、软素质 | 开放式设计题，看边界意识和沟通 | 单题 15～30 分钟 |
| HR 面 | 意愿度、稳定性、薪资 | 行为类问题，看表达与真实度 | 单题 2～5 分钟 |

由此可以推出两条实用结论：

1. **一面的失分点是「答不出」，二面三面的失分点是「答不深」。** 一面靠覆盖，二三面靠纵深，准备方式不一样。
2. **项目经历是二面的题源。** 你写在简历上的每个技术名词，都可能变成 15 分钟的追问。项目里说不清的技术选型，比答不上来的八股更致命。

## 面试官在每个深度想要什么

同一道题，面试官会根据你的回答逐层下探。可以用这张表自评当前停在哪一层：

| 深度 | 你的回答形态 | 面试官判断 |
| --- | --- | --- |
| L1 名词层 | 「HashMap 是数组加链表」 | 背过，但可能只是背过 |
| L2 机制层 | 「链表长度到 8 且容量到 64 会树化」 | 记得细节，可以继续问 |
| L3 因果层 | 「树化是为了把最坏查询从 O(n) 降到 O(log n)，代价是节点变大」 | 理解设计取舍，值得深聊 |
| L4 边界层 | 「阈值 6 和 8 之间留缓冲是为了避免临界抖动；并发下仍不安全」 | 知道适用边界，可以给高评价 |
| L5 迁移层 | 「同样的取舍在 ConcurrentHashMap 里换成了另一种做法，因为……」 | 能横向比较，可以聊架构 |

L3 是大多数岗位的及格线。只会 L1 的候选人，会在第二个追问上停下。

## 每篇怎么读

每家公司页面统一用下面的结构，你可以按需跳读：

```text
元信息块       → 先确认这页是什么时候的、可信到什么程度
考察权重分布   → 决定复习时间怎么分配
典型问法清单   → 对照自己的回答深度，查漏
追问链示例     → 看面试官会怎么往下挖
高频失分点     → 提前绕开
```

### 元信息块：先看它再读内容

每页顶部的三行元信息是本模块对抗「内容过期」的机制，读之前先扫一眼：

| 字段 | 你要用它判断什么 |
| --- | --- |
| 数据窗口 | 这批印象基于哪段时间的面经，是不是已经太旧 |
| 最近核对 | 这页最后一次被核对、修正的时间，判断它还有没有人管 |
| 来源性质 | 结论的强度——本模块统一是「公开面经归纳」或「针对性整理」，**不是官方题库** |

如果某页的「最近核对」距今天已经很久，读的时候就要自己打个折；也欢迎按 [贡献指南](../../CONTRIBUTING.md) 补上新的样本。

### 华为两页的特殊说明

华为的两个页面与其余六页的证据强度不同，读法也不同：

- **华为-Java后端.md**：基于公开面经与岗位画像整理的**考察侧重归纳**，其中专项练习题全部标记为**模拟题**，不是华为官方真题；
- **华为-AI软件工程.md**：岗位方向较新，公开可核验的面经样本有限，页面以**岗位技术域拆解 + 针对性练习题**为主，模拟题比例更高。

两页都严格区分「可溯源的公开信息」与「本仓库自行整理的练习题」，不要把练习题当真题背。

### 回答骨架不在这里

本目录只放**跨时间成立的考察画像**（哪家偏重什么、会怎么追）与专项练习；具体题目、频率标注与回答骨架统一收在 [专题题库](../01-专题题库/README.md)，一类题一个文件。两者分工明确，不重复维护同一道题——企业页面里的每道问法都链接回专题题库对应题目，那里维护唯一的标准答案。

### 想要可溯源的真题记录？

本目录只放**跨时间成立的考察画像**（会就地更新）。「2026 春招某场二面被问了什么」这类**带时间点的具体记录**，属于另一类内容，放 [真题记录](真题记录/README.md) 并标注时间、公司、题集名称与来源，不要混进画像页。判断标准：一条信息如果三个月后可能不再成立，它就是记录，不是画像。

## 使用提醒

- 页面中的「高频」标记表示**公开面经里反复出现**，不等于该公司的官方权重。
- 追问链展示的是**追问的方向**，不是逐字脚本。真实面试语速更快、更跳跃，不要按稿背。
- 如果某道题你只能答到 L1，直接点进页面里的权威文章，那才是知识该补的地方。
