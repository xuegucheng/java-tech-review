## 5.2 面向对象的基本思想

面向对象不是简单地把代码放进类中。
其核心思想是：
将数据以及操作这些数据的行为组织在同一个对象中，让对象负责维护自身状态和业务规则。

例如，库存对象可以同时包含：

- 当前库存数量
- 可用库存数量
- 锁定库存数量
- 库存扣减行为
- 库存锁定行为
- 库存释放行为
- 数量合法性校验
- 不推荐把对象设计成只有字段的纯数据容器，再由外部代码任意修改：

```java
public class Inventory {
    public int availableStock;
    public int lockedStock;
}
```

外部可以直接执行：

```
inventory.availableStock = -100;
```

对象无法保证自身状态合法。
更合理的设计：

```java
public class Inventory {
    private int availableStock;
    private int lockedStock;
    public void lock(int quantity) {
        if (quantity <= 0) {
            throw new IllegalArgumentException("锁定数量必须大于 0");
        }
        if (availableStock < quantity) {
            throw new IllegalStateException("可用库存不足");
        }
        availableStock -= quantity;
        lockedStock += quantity;
    }
}
```

此时库存对象自己维护：

```
availableStock >= 0
lockedStock >= 0
库存锁定不能超过可用库存
```

这类必须始终成立的条件称为对象不变量。

## 5.3 类与对象

**5.3.1 类是什么**

类是对一类事物的状态和行为进行抽象后形成的类型定义。
例如：

```java
public class User {
    private String name;
    private int age;
    public void introduce() {
        System.out.println("我是 " + name);
    }
}
```

其中：

```text
User
├── 状态
│ ├── name
│ └── age
└── 行为
└── introduce()
```

类描述：

- 对象可以保存哪些数据
- 对象可以执行哪些操作
- 外部可以访问哪些成员
- 对象如何被初始化
- 对象必须满足哪些约束

**5.3.2 对象是什么**

对象是类在运行时创建出的具体实例。

```
User user = new User();
```

这里：

```
User user new User()
类型 引用变量 创建对象
```

可以抽象为：

```text
user ─────→ User 对象
├── name = null
└── age = 0
```

同一个类可以创建多个对象：

```
User user1 = new User();
User user2 = new User();
```

user1 和 user2 通常指向两个不同对象。

```
user1 ─────→ User 对象1
user2 ─────→ User 对象2
```

它们具有相同的数据结构和方法定义，但保存各自独立的实例状态。

**5.3.3 类不等于对象**

类是类型定义，对象是运行时实例。
例如：

```
User user = new User();
```

不能把 User 、 user 和 new User() 混为一谈：

- 表达式 含义
- User 类或类型
- user 引用变量
- new User() 创建 User 对象
- user.name 通过引用访问对象成员

**5.3.4 一个引用变量可以指向不同对象**

```
User user = new User();
user = new User();
```

第一次创建的对象与第二次创建的对象不同。
执行重新赋值后：

```
原来：
user ─────→ 对象A
重新赋值：
user ─────→ 对象B
对象A 不再由 user 引用
```

如果对象 A 不再被任何可达引用指向，它可能在之后被垃圾回收。
但具体 GC 机制放在 JVM 模块。

**5.3.5 多个引用可以指向同一个对象**

```
User user1 = new User();
User user2 = user1;
```

此时：

```text
user1 ─────┐
├────→ 同一个 User 对象
user2 ─────┘
```

通过任意一个引用修改对象：

```
user2.setName("Java");
```

user1 也能观察到变化。
原因不是两个变量相同，而是它们指向同一个对象。

## 5.5 字段与对象状态

字段用于保存对象或类的状态。

```java
public class Order {
    private String orderNo;
    private OrderStatus status;
    private int totalQuantity;
}
```

**5.5.1 实例字段**

没有使用 static 修饰的字段称为实例字段。

```java
private String orderNo;
```

每个对象拥有自己的一份实例字段：

```
Order order1 = new Order();
Order order2 = new Order();
```

可以抽象为：

```text
order1 ──→ Order对象1
├── orderNo
├── status
└── totalQuantity
order2 ──→ Order对象2
├── orderNo
├── status
└── totalQuantity
```

修改 order1 的字段不会自动修改 order2 。

**5.5.2 字段的默认值**

实例字段在对象创建时会获得默认值：

- 类型 默认值
- 数值类型
- 或对应零值
- boolean false
- char '\u0000'
- 引用类型 null
- 例如：

```java
public class User {
    private int age;
    private boolean active;
    private String name;
}
```

执行：

```
User user = new User();
```

初始状态大致为：

```
age = 0
active = false
name = null
```

但默认值不一定符合业务要求。
例如：

```
status = null
```

往往不是合法订单状态。
因此业务对象通常应通过构造方法建立有效初始状态。

**5.5.3 字段声明时初始化**

```java
public class Order {
    private OrderStatus status = OrderStatus.CREATED;
    private List<OrderItem> items = new ArrayList<>();
}
```

这样每次创建对象时，字段都会获得声明处指定的初始值。
需要注意可变对象字段：

```java
private List<OrderItem> items = new ArrayList<>();
```

这是实例字段时，每个对象都会创建自己的一份列表。
但如果加上 static ：

```java
private static List<OrderItem> items = new ArrayList<>();
```

所有对象会共享同一个列表。
静态字段后续章节展开。

## 5.6 方法与对象行为

实例方法用于描述对象能够执行的行为。

```java
public class Order {
    private OrderStatus status;
    public void cancel() {
        status = OrderStatus.CANCELED;
    }
}
```

调用：

```
order.cancel();
```

可以理解为：

```
让 order 指向的对象执行 cancel 行为
```

**5.6.1 实例方法可以访问实例字段**

```
public void cancel() {
status = OrderStatus.CANCELED;
}
```

这里虽然没有写：

```
this.status
```

实际上访问的是当前对象的字段。
可以显式写成：

```
public void cancel() {
this.status = OrderStatus.CANCELED;
}
```

**5.6.2 行为比 Setter 更能表达业务语义**

不推荐：

```
order.setStatus(OrderStatus.CANCELED);
```

这种写法只是把字段改成某个值，没有表达：

- 当前状态是否允许取消
- 取消时间是什么
- 谁执行了取消
- 是否需要释放库存
- 是否需要记录取消原因
- 更合理：

```
order.cancel(operatorId, reason);
```

方法内部维护业务规则：

```
public void cancel(String operatorId, String reason) {
if (status == OrderStatus.COMPLETED) {
throw new IllegalStateException("已完成订单不能取消");
}
if (status == OrderStatus.CANCELED) {
return;
}
this.status = OrderStatus.CANCELED;
this.cancelOperatorId = operatorId;
this.cancelReason = reason;
this.cancelTime = LocalDateTime.now();
}
```

核心思想：
对象应暴露业务行为，而不是把全部状态修改权交给外部。

## 5.7 对象创建

最常见的对象创建方式：

```
User user = new User();
```

其中 new 表示创建新的对象实例。
从语言层面可以理解为：

```
为对象准备空间
↓
字段设置默认值
↓
执行字段初始化表达式
↓
执行实例代码块
↓
执行构造方法
↓
返回对象引用
```

父子类情况下还涉及父类初始化，放到继承章节进一步说明。

**5.7.1 new 每次通常创建新对象**

```
User user1 = new User();
User user2 = new User();
System.out.println(user1 == user2); // false
```

两个 new User() 通常产生两个不同对象。

但对象创建可能受到：

- 字符串池
- 包装类缓存
- 工厂缓存
- 单例模式
- JVM 优化

影响。
因此更准确地说：
对普通类直接执行两次 new ，语言语义上会产生两个不同对象实例。
