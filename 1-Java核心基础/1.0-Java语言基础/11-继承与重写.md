## 6.2 继承是什么

继承用于表达一种类型之间的“是一个”关系：

```
Dog 是一种 Animal
Manager 是一种 Employee
SavingsAccount 是一种 Account
```

4
Java 使用 extends 表示类继承：

```java
public class Animal {
```

2

```
protected String name;
```

4

```
public void eat() {
System.out.println(name + " 正在进食");
}
}
```

9
子类：

```java
public class Dog extends Animal {
```

2

```
public void bark() {
System.out.println(name + " 正在叫");
}
}
```

7
创建对象：

```
Dog dog = new Dog();
dog.name = "旺财";
dog.eat();
dog.bark();
```

5
Dog 对象既具备：
Animal 定义的状态和行为
Dog 自己新增的状态和行为

**6.2.1 继承的主要作用**

继承主要提供：
1.代码复用
2.建立类型层次
3.支持方法重写
4.支持运行时多态
5.抽取公共契约和行为
但继承不应只为了减少代码重复。
更重要的是：
子类在语义上应当真正属于父类所描述的类型。
例如：

```
Dog extends Animal
```

2
语义合理。
但：

```
Car extends Engine
```

2
通常不合理，因为汽车不是一种发动机，汽车只是拥有发动机。
更适合使用组合：

```java
public class Car {
```

2

```java
private Engine engine;
}
```

## 6.3 Java 类的单继承

Java 类只支持单继承：

```java
public class Child extends Parent {
}
```

3
一个类不能同时继承两个类：

```java
public class Child extends ParentA, ParentB {
}
```

3
这是非法语法。

**6.3.1 为什么类不支持多继承**

多继承容易引入：
成员来源冲突
同名方法冲突
状态初始化复杂
菱形继承问题
类型层次难以维护
典型菱形结构：

```
Parent
/ \
ChildA ChildB
\ /
GrandChild
```

6
如果 ChildA 和 ChildB 对同一个方法有不同实现， GrandChild 很难确定应该继承哪一个。
Java 的选择是：

```
类：单继承
接口：多实现
```

3
通过接口提供多能力组合。

**6.3.2 所有类最终都继承 Object**

如果一个类没有显式写 extends ：

```java
public class User {
}
```

3
可以理解为：

```java
public class User extends Object {
}
```

3
因此所有普通 Java 类最终都继承自 java.lang.Object 。
由此获得：
toString()
equals()
hashCode()
getClass()
wait()
notify()
notifyAll()
等方法。
Object 的完整契约后续单独展开。

## 6.4 子类继承了什么

继承不能简单理解为“把父类代码复制到子类”。
更准确地说：
子类对象包含父类定义的实例状态，并能够使用父类允许访问的成员。
例如：

```java
public class Parent {
```

2

```java
public int publicValue;
protected int protectedValue;
int packageValue;
private int privateValue;
```

7

```
public void publicMethod() {
}
```

10

```
protected void protectedMethod() {
}
```

13

```java
private void privateMethod() {
}
}
```

17
子类：

```java
public class Child extends Parent {
```

2

```
public void test() {
publicValue = 1;
protectedValue = 2;
```

6

```
publicMethod();
protectedMethod();
}
}
```

**6.4.1 private 成员是否被继承**

这是一个常见争议点。
从对象结构角度看：
子类对象中包含父类定义的 private 状态。
父类方法仍然可以访问这些 private 字段。
但从源码访问角度看：
子类不能直接访问父类 private 成员。
private 成员不会成为子类可直接使用的成员。
例如：

```java
public class Parent {
```

2

```java
private String name;
```

4

```
public String getName() {
return name;
}
}
```

9
子类：

```java
public class Child extends Parent {
```

2

```
public void test() {
// name = "Java";
// 编译错误
```

6

```
System.out.println(getName());
}
}
```

10
更准确的表达：
父类 private 状态是子类对象中父类部分的一部分，但对子类源码不可直接访问，只能通过父类提供的非 private 方法间接使用。

**6.4.2 构造方法不会被继承**

父类构造方法：

```java
public class Parent {
```

2

```
public Parent(String name) {
}
}
```

6
子类不能像调用普通方法一样直接继承该构造方法：

```
Child child = new Child("Java");
```

2
只有子类自己定义对应构造方法时才可以：

```java
public class Child extends Parent {
```

2

```
public Child(String name) {
super(name);
}
}
```

7
因此：
构造方法不属于普通继承成员，子类必须通过 super() 调用父类构造方法。

**6.4.3 静态成员的继承**

静态成员属于类，而不是对象。
子类可以通过语法访问父类静态成员：

```java
public class Parent {
```

2

```java
public static int count;
}
```

5

```java
public class Child extends Parent {
}
```

3
可以写：

```
Child.count = 10;
```

2
但 count 实际仍然是 Parent 定义的静态字段，并不是每个子类对象各自拥有一份。
更推荐通过声明类访问：

```
Parent.count = 10;
```

2
以避免误解。
静态方法也不具有实例方法那样的运行时多态，后面详细讨论。

## 6.5 super 关键字

super 用于访问当前对象的父类部分。
常见用途：
1.调用父类构造方法
2.调用父类方法
3.访问父类字段

**6.5.1 调用父类构造方法**

```java
public class Parent {
```

2

```java
private final String name;
```

4

```
public Parent(String name) {
this.name = name;
}
}
```

9
子类：

```java
public class Child extends Parent {
```

2

```
public Child(String name) {
super(name);
}
}
```

7
super(name) 表示调用父类对应构造方法。

**6.5.2 super() 必须位于第一行**

正确：

```
public Child(String name) {
super(name);
System.out.println("Child");
}
```

5
错误：

```
public Child(String name) {
System.out.println("Child");
super(name);
}
```

5
原因是：
在初始化子类自己的状态之前，必须先完成父类部分的初始化。

**6.5.3 编译器隐式添加 super()**

如果子类构造方法没有显式调用：

```
public Child() {
}
```

3
编译器会尝试插入：

```
public Child() {
super();
}
```

4
因此，如果父类没有无参构造方法：

```java
public class Parent {
```

2

```
public Parent(String name) {
}
}
```

6
子类：

```java
public class Child extends Parent {
```

2

```
public Child() {
}
}
```

6
会编译失败。
因为编译器尝试调用：

```
super();
```

2
但父类不存在无参构造方法。
正确：

```
public Child() {
super("default");
}
```

4

**6.5.4 调用父类方法**

```java
public class Parent {
```

2

```
public void execute() {
System.out.println("Parent execute");
}
}
```

7
子类：

```java

```

2


9
输出：

```

Child execute
```

3
super.execute() 用于明确调用父类实现。

**6.5.5 访问父类字段**

```java
public class Parent {
```

2

```
protected String name = "Parent";
}
```

5
子类：

```java
public class Child extends Parent {
```

2

```java
private String name = "Child";
```

4

```
public void print() {
System.out.println(name);
System.out.println(this.name);
System.out.println(super.name);
}
}
```

11
输出：

```

Child
Parent
```

4
其中：
name ：当前作用域最近的字段
this.name ：当前对象的子类字段
super.name ：当前对象的父类字段
需要注意：
父类字段和子类同名字段是两个不同字段，不是方法重写。
这种现象称为字段隐藏。

## 6.6 父子类初始化顺序

创建子类对象时，必须先初始化父类部分，再初始化子类部分。
完整顺序可以概括为：

```
父类静态字段与静态代码块
↓
子类静态字段与静态代码块
↓
父类实例字段与实例代码块
↓
父类构造方法
↓
子类实例字段与实例代码块
↓
子类构造方法
```

12
静态部分只在类初始化时执行一次。
实例部分每创建一个对象执行一次。

**6.6.1 初始化顺序示例**

父类：

```java
public class Parent {
```

2

```

}
```

6

```
{

}
```

```
public Parent() {
System.out.println("父类构造方法");
}
}
```

15

```java
public class Child extends Parent {
```

2

```
static {
System.out.println("子类静态代码块");
}
```

6

```
{
System.out.println("子类实例代码块");
}
```

```
public Child() {
System.out.println("子类构造方法");
}
```

子类对象包含父类部分。
在初始化子类之前，父类定义的状态必须先合法建立。
例如：

```java
public class Account {
```

```java

```

```

this.accountNo = accountNo;
}
}
```

9
子类：

```java

```

2

4

```
}
```

必须先保证 Account 部分已经完成初始化，才能继续建立 SavingsAccount 状态。

**6.6.3 父类构造中调用重写方法的风险**

父类：

```java
public class Parent {
```

2

```
public Parent() {
print();
}
```

6

```
protected void print() {
System.out.println("Parent");
}
}
```

11
子类：

```java
public class Child extends Parent {
```

2

```java
private String name = "Java";
```

4

```
@Override
protected void print() {
System.out.println(name.length());
}
}
```

10
执行：

```
new Child();
```

2
可能抛出 NullPointerException 。
原因：

```
开始创建 Child
↓
先执行 Parent 构造方法
↓
Parent 构造方法调用 print()
↓
动态绑定到 Child.print()
↓
Child.name 尚未完成初始化
↓
name 仍然是默认值 null
```

12
因此：
构造方法中不要调用可能被子类重写的方法。
更安全的是调用：
private 方法
final 方法
static 方法
明确不会被重写的方法
