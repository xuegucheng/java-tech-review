# 继承与重写

## 11.1 本章定位

继承与多态是 Java 面向对象模型的核心。

这一章主要解决以下问题：

- Java 继承到底继承了什么？
- 子类能否访问父类的所有成员？
- private 成员的边界是什么？
- 构造方法是否会被继承？
- super 的作用是什么？
- 父类和子类的初始化顺序是什么？

方法重写的完整规则、多态和动态绑定见 12-多态与动态绑定。

本章核心主线：

```
父类抽取公共能力
↓
子类继承父类成员
↓
子类扩展行为
↓
super 调用父类构造和方法
↓
父子类初始化顺序
```

本章暂不深入：

- 方法重写规则与多态：见 12-多态与动态绑定。
- 抽象类和接口：见 13-抽象类、14-接口设计。

## 11.2 继承是什么

继承用于表达一种类型之间的“是一个”关系：

```
Dog 是一种 Animal
Manager 是一种 Employee
SavingsAccount 是一种 Account
```

Java 使用 extends 表示类继承：

```java
public class Animal {
    protected String name;
    public void eat() {
        System.out.println(name + " 正在进食");
    }
}
```

子类：

```java
public class Dog extends Animal {
    public void bark() {
        System.out.println(name + " 正在叫");
    }
}
```

创建对象：

```
Dog dog = new Dog();
dog.name = "旺财";
dog.eat();
dog.bark();
```

Dog 对象既具备：

- Animal 定义的状态和行为
- Dog 自己新增的状态和行为

**11.2.1 继承的主要作用**

继承主要提供：

- 1.代码复用
- 2.建立类型层次
- 3.支持方法重写
- 4.支持运行时多态
- 5.抽取公共契约和行为

但继承不应只为了减少代码重复。
更重要的是：
子类在语义上应当真正属于父类所描述的类型。
例如：

```
Dog extends Animal
```

语义合理。
但：

```
Car extends Engine
```

通常不合理，因为汽车不是一种发动机，汽车只是拥有发动机。
更适合使用组合：

```java
public class Car {
    private Engine engine;
}
```

## 11.3 Java 类的单继承

Java 类只支持单继承：

```java
public class Child extends Parent {
}
```

一个类不能同时继承两个类：

```java
public class Child extends ParentA, ParentB {
}
```

这是非法语法。

**11.3.1 为什么类不支持多继承**

多继承容易引入：

- 成员来源冲突
- 同名方法冲突
- 状态初始化复杂
- 菱形继承问题
- 类型层次难以维护
- 典型菱形结构：

```
Parent
/ \
ChildA ChildB
\ /
GrandChild
```

如果 ChildA 和 ChildB 对同一个方法有不同实现， GrandChild 很难确定应该继承哪一个。
Java 的选择是：

```
类：单继承
接口：多实现
```

通过接口提供多能力组合。

**11.3.2 所有类最终都继承 Object**

如果一个类没有显式写 extends ：

```java
public class User {
}
```

可以理解为：

```java
public class User extends Object {
}
```

因此所有普通 Java 类最终都继承自 java.lang.Object 。

由此获得：

- toString()
- equals()
- hashCode()
- getClass()
- wait()
- notify()
- notifyAll()

等方法。
Object 的完整契约后续单独展开。

## 11.4 子类继承了什么

继承不能简单理解为“把父类代码复制到子类”。
更准确地说：
子类对象包含父类定义的实例状态，并能够使用父类允许访问的成员。
例如：

```java
public class Parent {
    public int publicValue;
    protected int protectedValue;
    int packageValue;
    private int privateValue;
    public void publicMethod() {
    }
    protected void protectedMethod() {
    }
    private void privateMethod() {
    }
}
```

子类：

```java
public class Child extends Parent {
    public void test() {
        publicValue = 1;
        protectedValue = 2;
        publicMethod();
        protectedMethod();
    }
}
```

**11.4.1 private 成员是否被继承**

这是一个常见争议点。

从对象结构角度看：

- 子类对象中包含父类定义的 private 状态。
- 父类方法仍然可以访问这些 private 字段。

但从源码访问角度看：

- 子类不能直接访问父类 private 成员。
- private 成员不会成为子类可直接使用的成员。

例如：

```java
public class Parent {
    private String name;
    public String getName() {
        return name;
    }
}
```

子类：

```java
public class Child extends Parent {
    public void test() {
        // name = "Java";
        // 编译错误
        System.out.println(getName());
    }
}
```

更准确的表达：
父类 private 状态是子类对象中父类部分的一部分，但对子类源码不可直接访问，只能通过父类提供的非 private 方法间接使用。

**11.4.2 构造方法不会被继承**

父类构造方法：

```java
public class Parent {
    public Parent(String name) {
    }
}
```

子类不能像调用普通方法一样直接继承该构造方法：

```
Child child = new Child("Java");
```

只有子类自己定义对应构造方法时才可以：

```java
public class Child extends Parent {
    public Child(String name) {
        super(name);
    }
}
```

因此：
构造方法不属于普通继承成员，子类必须通过 super() 调用父类构造方法。

**11.4.3 静态成员的继承**

静态成员属于类，而不是对象。
子类可以通过语法访问父类静态成员：

```java
public class Parent {
    public static int count;
}
public class Child extends Parent {
}
```

可以写：

```
Child.count = 10;
```

但 count 实际仍然是 Parent 定义的静态字段，并不是每个子类对象各自拥有一份。
更推荐通过声明类访问：

```
Parent.count = 10;
```

以避免误解。
静态方法也不具有实例方法那样的运行时多态，后面详细讨论。

## 11.5 super 关键字

super 用于访问当前对象的父类部分。

常见用途：

- 1.调用父类构造方法
- 2.调用父类方法
- 3.访问父类字段

**11.5.1 调用父类构造方法**

```java
public class Parent {
    private final String name;
    public Parent(String name) {
        this.name = name;
    }
}
```

子类：

```java
public class Child extends Parent {
    public Child(String name) {
        super(name);
    }
}
```

super(name) 表示调用父类对应构造方法。

**11.5.2 super() 的位置规则**

Java 21 及之前，显式 super(...) 必须是构造方法体中的第一条语句。

Java 22 首次以预览特性提供构造器调用前语句；Java 23 进行第二次预览；Java 24 进行第三次预览。在 Java 22～24 中使用该能力，需要启用对应版本的预览特性。

Java 25 起，Flexible Constructor Bodies 正式交付，不再属于预览特性。

传统规则（Java 21 及之前）：

正确：

```java
public Child(String name) {
    super(name);
    System.out.println("Child");
}
```

错误（Java 21 及之前）：

```java
public Child(String name) {
    System.out.println("Child");
    super(name);
}
```

原因是：
在初始化子类自己的状态之前，必须先完成父类部分的初始化。

Java 25 起允许的写法：

```java
public Child(String name) {
    if (name == null || name.isBlank()) {
        throw new IllegalArgumentException("name 不能为空");
    }

    super(name);
}
```

以上写法在 Java 25 中正式支持；Java 22～24 需要启用预览特性；Java 21 及之前不能编译。

限制说明：
* 构造器调用前不是任意代码区域；
* 不能通过 this 读取当前对象状态；
* 不能调用当前对象的实例方法；
* 不能让当前对象在父类构造完成前逸出；
* 不要写成"super 可以放在构造方法任意位置"。

**11.5.3 编译器隐式添加 super()**

如果子类构造方法没有显式调用：

```
public Child() {
}
```

编译器会尝试插入：

```
public Child() {
super();
}
```

因此，如果父类没有无参构造方法：

```java
public class Parent {
    public Parent(String name) {
    }
}
```

子类：

```java
public class Child extends Parent {
    public Child() {
    }
}
```

会编译失败。
因为编译器尝试调用：

```
super();
```

但父类不存在无参构造方法。
正确：

```
public Child() {
super("default");
}
```

**11.5.4 调用父类方法**

```java
public class Parent {
    public void execute() {
        System.out.println("Parent execute");
    }
}
```

子类：

```java
public class Child extends Parent {
    @Override
    public void execute() {
        super.execute();
        System.out.println("Child execute");
    }
}
```

输出：

```
Parent execute
Child execute
```

super.execute() 用于明确调用父类实现。

**11.5.5 访问父类字段**

```java
public class Parent {
    protected String name = "Parent";
}
```

子类：

```java
public class Child extends Parent {
    private String name = "Child";
    public void print() {
        System.out.println(name);
        System.out.println(this.name);
        System.out.println(super.name);
    }
}
```

输出：

```
Child
Child
Parent
```

其中：

- name ：当前作用域最近的字段
- this.name ：当前对象的子类字段
- super.name ：当前对象的父类字段
- 需要注意：

父类字段和子类同名字段是两个不同字段，不是方法重写。
这种现象称为字段隐藏。

## 11.6 父子类初始化顺序

创建子类对象时，必须先初始化父类部分，再初始化子类部分。
完整顺序可以概括为：

```
父类静态字段与静态代码块
↓
子类静态字段与静态代码块
↓
父类实例字段与实例代码块
↓
父类构造方法
↓
子类实例字段与实例代码块
↓
子类构造方法
```

静态部分只在类初始化时执行一次。
实例部分每创建一个对象执行一次。

**11.6.1 初始化顺序示例**

父类：

```java
public class Parent {
    static {
        System.out.println("父类静态代码块");
    }
    {
        System.out.println("父类实例代码块");
    }
    public Parent() {
        System.out.println("父类构造方法");
    }
}
```

子类：

```java
public class Child extends Parent {
    static {
        System.out.println("子类静态代码块");
    }
    {
        System.out.println("子类实例代码块");
    }
    public Child() {
        System.out.println("子类构造方法");
    }
}
```

执行：

```
new Child();
```

第一次运行时输出：

```
父类静态代码块
子类静态代码块
父类实例代码块
父类构造方法
子类实例代码块
子类构造方法
```

再次创建：

```
new Child();
```

只输出：

```
父类实例代码块
父类构造方法
子类实例代码块
子类构造方法
```

静态初始化不会重复执行。

**11.6.2 为什么先调用父类构造方法**

- 子类对象包含父类部分。
- 在初始化子类之前，父类定义的状态必须先合法建立。

例如：

```java
public class Account {
    private final String accountNo;
    public Account(String accountNo) {
        this.accountNo = accountNo;
    }
}
```

子类：

```java
public class SavingsAccount extends Account {
    private BigDecimal interestRate;
    public SavingsAccount(
    String accountNo,
    BigDecimal interestRate
    ) {
        super(accountNo);
        this.interestRate = interestRate;
    }
}
```

必须先保证 Account 部分已经完成初始化，才能继续建立 SavingsAccount 状态。

**11.6.3 父类构造中调用重写方法的风险**

父类：

```java
public class Parent {
    public Parent() {
        print();
    }
    protected void print() {
        System.out.println("Parent");
    }
}
```

子类：

```java
public class Child extends Parent {
    private String name = "Java";
    @Override
    protected void print() {
        System.out.println(name.length());
    }
}
```

执行：

```
new Child();
```

可能抛出 NullPointerException 。
原因：

```
开始创建 Child
↓
先执行 Parent 构造方法
↓
Parent 构造方法调用 print()
↓
动态绑定到 Child.print()
↓
Child.name 尚未完成初始化
↓
name 仍然是默认值 null
```

因此：
构造方法中不要调用可能被子类重写的方法。

更安全的是调用：

- private 方法
- final 方法
- static 方法
- 明确不会被重写的方法

## 11.7 方法重写概览

方法重写是指子类对父类可继承的实例方法提供新的实现，是运行时多态的基础。

```java
public class Animal {
    public void speak() {
        System.out.println("Animal sound");
    }
}

public class Dog extends Animal {
    @Override
    public void speak() {
        System.out.println("Dog bark");
    }
}
```

调用：

```
Animal animal = new Dog();
animal.speak();
```

输出：

```
Dog bark
```

重写需要满足：方法名和参数列表相同、返回类型兼容、访问权限不能缩小、受检异常不能扩大。`@Override` 注解可以让编译器协助校验重写关系是否成立。

> 完整重写规则、重载与重写对比、动态绑定机制见 12-多态与动态绑定。

## 11.8 建议实验

实验一：验证继承的成员范围

```java
public class Parent {
    public int publicValue;
    protected int protectedValue;
    int packageValue;
    private int privateValue;
}

public class Child extends Parent {
    public void test() {
        publicValue = 1;
        protectedValue = 2;
        packageValue = 3;
        // privateValue = 4; // 编译错误
    }
}
```

在子类中注释和取消注释各字段赋值，观察编译器报错范围，理解访问控制对继承成员的影响。

实验二：super() 的位置规则

```java
public class Parent {
    public Parent(String name) {
    }
}

public class Child extends Parent {
    public Child() {
        // super(); // 编译器隐式插入，父类无无参构造则失败
        super("default");
        System.out.println("Child");
    }
}
```

分别尝试省略 `super(...)`、放在第一行、放在方法体中部，对比 Java 21 与 Java 25 的编译行为。

实验三：父子类初始化顺序

```java
public class Parent {
    static { System.out.println("父类静态"); }
    { System.out.println("父类实例"); }
    public Parent() { System.out.println("父类构造"); }
}

public class Child extends Parent {
    static { System.out.println("子类静态"); }
    { System.out.println("子类实例"); }
    public Child() { System.out.println("子类构造"); }

    public static void main(String[] args) {
        new Child();
        System.out.println("---");
        new Child();
    }
}
```

观察两次创建对象的输出差异，理解静态初始化只执行一次。

实验四：构造方法中调用重写方法的风险

```java
public class Parent {
    public Parent() { print(); }
    protected void print() { System.out.println("Parent"); }
}

public class Child extends Parent {
    private String name = "Java";
    @Override
    protected void print() { System.out.println(name.length()); }

    public static void main(String[] args) { new Child(); }
}
```

观察是否抛出 `NullPointerException`，理解动态绑定在构造阶段引发的初始化风险。

实验五：字段隐藏

```java
public class Parent {
    protected String name = "Parent";
}

public class Child extends Parent {
    private String name = "Child";
    public void print() {
        System.out.println(name);
        System.out.println(this.name);
        System.out.println(super.name);
    }
}
```

验证同名字段在不同作用域下的取值，理解字段隐藏不是重写。

## 11.10 易错点

**误区一：private 成员完全没有被继承**

**错误。**

子类对象在内存中仍然包含父类的 private 状态，只是子类源码不能直接访问，只能通过父类提供的非 private 方法间接使用。

**误区二：构造方法会被子类继承**

**错误。**

构造方法不属于普通继承成员。子类只能通过 `super(...)` 调用父类构造方法，并且需要自己声明对应的构造方法。

**误区三：super() 可以放在构造方法任意位置**

**错误。**

Java 21 及之前，显式 `super(...)` 必须是构造方法体的第一条语句。Java 25 虽然允许前置受限语句，但仍不能读取当前对象未初始化的实例状态，不是任意代码区域。

**误区四：父类没有无参构造方法时编译器仍会插入 super()**

**错误。**

编译器隐式插入的是 `super()`（无参），如果父类没有可访问的无参构造方法，插入后会编译失败。子类必须显式调用父类存在的有参构造方法。

**误区五：子类和父类同名字段会触发动态绑定**

**错误。**

字段访问根据引用的编译时类型绑定，没有运行时多态。同名字段属于字段隐藏，不是方法重写。

**误区六：构造方法中调用本类方法一定安全**

**错误。**

如果该方法不是 `private`、`final` 或 `static`，就有可能被子类重写，在父类构造阶段动态绑定到子类实现，而子类字段尚未初始化，可能引发空指针或状态不一致。

**误区七：静态成员每个子类对象各有一份**

**错误。**

静态成员属于类本身，不是每个对象一份。通过子类访问的静态成员仍然是父类定义的那一份。

## 11.11 本章总结

```
继承表达"是一个"类型关系
↓
子类继承父类允许访问的成员，private 状态不可直接访问
↓
构造方法不被继承，通过 super() 调用
↓
所有类最终继承 Object
↓
父子类初始化顺序：静态 → 父实例 → 父构造 → 子实例 → 子构造
↓
构造方法中不要调用可重写方法
```

面试口述版：

- 继承用于表达类型之间的"是一个"关系，Java 类只支持单继承，所有类最终继承 `Object`。子类继承父类允许访问的成员，`private` 状态存在于子类对象中但不能直接访问，只能通过父类非 private 方法间接使用。构造方法不被继承，子类通过 `super(...)` 调用父类构造方法，Java 21 及之前必须是第一条语句，Java 25 起允许前置受限语句。创建子类对象时先初始化父类静态、再子类静态，再父类实例与构造，最后子类实例与构造，静态部分只执行一次。构造方法中不应调用可重写方法，因为动态绑定可能在子类字段未初始化时执行子类实现。
