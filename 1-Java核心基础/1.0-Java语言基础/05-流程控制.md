# 第3章：流程控制

## 3.13 if 条件语句

### 3.13.1 基本结构
1 if (condition) {
2 // 条件成立
3 } else {
4 // 条件不成立
5 }
6
多分支：
1 if (score >= 90) {
2 grade = "A";
3 } else if (score >= 80) {
4 grade = "B";
5 } else if (score >= 60) {
6 grade = "C";
7 } else {
8 grade = "D";
9 }
10
### 3.13.2 条件必须是 boolean
Java 不允许：
1 if (1) {
2 }
3
也不允许：
1 int value = 1;
2
3 if (value) {
4 }
5
必须显式写为布尔表达式：
1 if (value != 0) {
2 }

3
### 3.13.3 大括号建议始终保留
语法允许：
1 if (success)
2 execute();
3
但推荐：
1 if (success) {
2 execute();
3 }
4
原因：
后续增加语句时不容易出错
代码结构更清楚
减少缩进误导
符合大多数团队规范
### 3.13.4 卫语句
复杂嵌套：
1 if (user != null) {
2 if (user.isActive()) {
3 if (user.hasPermission()) {
4 execute();
5 }
6 }
7 }
8
可以改为卫语句：
1 if (user == null) {
2 return;
3 }
4
5 if (!user.isActive()) {
6 return;
7 }
8
9 if (!user.hasPermission()) {
10 return;
11 }
12
13 execute();

14
优点：
减少嵌套
异常路径提前返回
主流程更加清晰
更容易维护

## 3.14 switch 语句

### 3.14.1 传统 switch
1 switch (status) {
2 case 1:
3 result = "待处理";
4 break;
5 case 2:
6 result = "处理中";
7 break;
8 case 3:
9 result = "已完成";
10 break;
11 default:
12 result = "未知";
13 }
14
传统 switch 中， break 用于防止继续执行后续分支。
### 3.14.2 switch 支持的类型
传统 Java switch 常见支持：
byte
short
char
int
对应包装类型
String
enum
不直接支持：
long
float
double
普通对象类型
现代模式匹配 switch 扩展了类型匹配能力，但本节先讲基础语义。
### 3.14.3 case 必须是编译期常量
1 final int A = 1;
2
3 switch (value) {
4 case A:

5 break;
6 }
7
可以编译，因为 A 是编译期常量。
但：
1 final int A = Integer.parseInt("1");
2
3 switch (value) {
4 case A: // 编译错误
5 break;
6 }
7
虽然 A 是 final ，但其值需要运行时计算，不是编译期常量。
### 3.14.4 case 穿透
1 switch (value) {
2 case 1:
3 System.out.println("A");
4 case 2:
5 System.out.println("B");
6 default:
7 System.out.println("C");
8 }
9
如果 value == 1 ，输出：
1 A
2 B
3 C
4
因为没有 break ，程序会继续执行后续分支。
有时穿透是有意使用：
1 switch (month) {
2 case 1:
3 case 3:
4 case 5:
5 case 7:
6 case 8:
7 case 10:
8 case 12:
9 days = 31;
10 break;
11 }
12
但现代 switch 表达式通常更清晰。

## 3.15 switch 表达式

现代 Java 支持箭头形式：
1 String result = switch (status) {
2 case 1 -> "待处理";
3 case 2 -> "处理中";
4 case 3 -> "已完成";
5 default -> "未知";
6 };
7
优点：
不需要 break
不会意外穿透
可以直接返回结果
编译器检查分支完整性
表达式更加简洁
### 3.15.1 多标签合并
1 int days = switch (month) {
2 case 1, 3, 5, 7, 8, 10, 12 -> 31;
3 case 4, 6, 9, 11 -> 30;
4 case 2 -> 28;
5 default -> throw new IllegalArgumentException("非法月份");
6 };
7
### 3.15.2 使用 yield 返回值
当分支需要多条语句时：
1 String result = switch (status) {
2 case 1 -> {
3 log.info("待处理状态");
4 yield "待处理";
5 }
6 case 2 -> {
7 log.info("处理中状态");
8 yield "处理中";
9 }
10 default -> "未知";
11 };
12
yield 用于从 switch 分支返回表达式结果。
它不是方法级别的 return 。
### 3.15.3 枚举 switch

1 String description = switch (status) {
2 case CREATED -> "已创建";
3 case PROCESSING -> "处理中";
4 case COMPLETED -> "已完成";
5 case CANCELED -> "已取消";
6 };
7
当枚举值全部覆盖时，可以不写 default 。
这样新增枚举常量后，编译器可能提示分支不完整，有利于代码演进。

## 3.16 for 循环

### 3.16.1 基本结构
1 for (初始化; 条件; 更新) {
2 // 循环体
3 }
4
示例：
1 for (int i = 0; i < 10; i++) {
2 System.out.println(i);
3 }
4
执行顺序：
1 初始化
2 ↓
3 判断条件
4 ↓
5 执行循环体
6 ↓
7 执行更新表达式
8 ↓
9 重新判断条件
10
初始化部分只执行一次。
### 3.16.2 多变量控制
1 for (int left = 0, right = array.length - 1;
2 left < right;
3 left++, right--) {
4 }
5

适合双指针场景，但不宜写得过于复杂。
### 3.16.3 无限循环
1 for (;;) {
2 }
3
与：
1 while (true) {
2 }
3
语义相近。
无限循环必须有明确退出机制，例如：
break
return
中断标志
外部状态变化

## 3.17 增强 for 循环

1 for (String value : list) {
2 System.out.println(value);
3 }
4
适用于：
数组
实现 Iterable 的对象
其核心目标是遍历元素，而不是控制索引。
### 3.17.1 增强 for 不适合需要索引的场景
错误做法：
1 int index = 0;
2
3 for (String value : list) {
4 process(index++, value);
5 }
6
如果索引本身具有业务意义，更适合普通 for 。
### 3.17.2 增强 for 中修改变量不等于修改容器

1 for (String value : list) {
2 value = value.trim();
3 }
4
这只是修改局部变量 value 的引用，不会替换列表中的元素。
如果要修改列表：
1 for (int i = 0; i < list.size(); i++) {
2 list.set(i, list.get(i).trim());
3 }
4
### 3.17.3 遍历时删除元素
1 for (String value : list) {
2 if (value.isEmpty()) {
3 list.remove(value);
4 }
5 }
6
通常会导致：
1 ConcurrentModificationException
2
正确方式之一：
1 Iterator<String> iterator = list.iterator();
2
3 while (iterator.hasNext()) {
4 String value = iterator.next();
5
6 if (value.isEmpty()) {
7 iterator.remove();
8 }
9 }
10
集合迭代器的具体机制放在集合章节。

## 3.18 while 与 do-while

### 3.18.1 while
1 while (condition) {
2 // 循环体

3 }
4
先判断条件，再执行循环体。
因此可能一次都不执行。
### 3.18.2 do-while
1 do {
2 // 循环体
3 } while (condition);
4
先执行一次，再判断条件。
因此至少执行一次。
注意结尾有分号：
1 while (condition);
2
### 3.18.3 适用场景
while 常用于：
不确定循环次数
按状态持续执行
读取流或消息
重试逻辑
do-while 常用于：
菜单交互
至少执行一次的校验
首次执行后再判断是否继续

## 3.19 break、continue 与 return

### 3.19.1 break
break 用于终止：
当前循环
当前 switch
1 for (int value : values) {
2 if (value == target) {
3 break;
4 }
5 }
6
只退出最内层循环。
### 3.19.2 continue

continue 用于跳过当前循环剩余部分，进入下一轮：
1 for (String value : values) {
2 if (value == null) {
3 continue;
4 }
5
6 process(value);
7 }
8
适合用来减少嵌套。
### 3.19.3 return
return 用于结束整个方法：
1 public void execute(User user) {
2 if (user == null) {
3 return;
4 }
5
6 process(user);
7 }
8
有返回值的方法：
1 public int add(int a, int b) {
2 return a + b;
3 }
4
### 3.19.4 三者区别
关键字 影响范围
break 结束当前循环或 switch
continue 跳过当前轮循环
return 结束整个方法

## 3.20 标签语句

Java 支持标签：
1 outer:
2 for (int i = 0; i < 10; i++) {
3 for (int j = 0; j < 10; j++) {
4 if (condition) {
5 break outer;
6 }

7 }
8 }
9
可以直接退出外层循环。
也可以：
1 continue outer;
2
直接进入外层循环下一轮。
标签语句虽然合法，但应谨慎使用：
容易降低可读性
复杂控制流难维护
通常可以拆分方法或使用标志变量替代
适合保留为了解内容，不应作为常规写法。
