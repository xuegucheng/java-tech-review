# 流程控制

## 3.13 if 条件语句

**3.13.1 基本结构**

```
if (condition) {
// 条件成立
} else {
// 条件不成立
}
```

多分支：

```
if (score >= 90) {
grade = "A";
} else if (score >= 80) {
grade = "B";
} else if (score >= 60) {
grade = "C";
} else {
grade = "D";
}
```

**3.13.2 条件必须是 boolean**

Java 不允许：

```
if (1) {
}
```

也不允许：

```
int value = 1;
if (value) {
}
```

必须显式写为布尔表达式：

```
if (value != 0) {
}
```

**3.13.3 大括号建议始终保留**

语法允许：

```
if (success)
execute();
```

但推荐：

```
if (success) {
execute();
}
```

原因：

- 后续增加语句时不容易出错
- 代码结构更清楚
- 减少缩进误导
- 符合大多数团队规范

**3.13.4 卫语句**

复杂嵌套：

```
if (user != null) {
if (user.isActive()) {
if (user.hasPermission()) {
execute();
}
}
}
```

可以改为卫语句：

```
if (user == null) {
return;
}
if (!user.isActive()) {
return;
}
if (!user.hasPermission()) {
return;
}
execute();
```

优点：

- 减少嵌套
- 异常路径提前返回
- 主流程更加清晰
- 更容易维护

## 3.14 switch 语句

**3.14.1 传统 switch**

```
switch (status) {
case 1:
result = "待处理";
break;
case 2:
result = "处理中";
break;
case 3:
result = "已完成";
break;
default:
result = "未知";
}
```

传统 switch 中， break 用于防止继续执行后续分支。

**3.14.2 switch 支持的类型**

传统 Java switch 常见支持：

- byte
- short
- char
- int
- 对应包装类型
- String
- enum
- 不直接支持：
- long
- float
- double
- 普通对象类型
现代模式匹配 switch 扩展了类型匹配能力，但本节先讲基础语义。

**3.14.3 case 必须是编译期常量**

```
final int A = 1;
switch (value) {
case A:
break;
}
```

可以编译，因为 A 是编译期常量。
但：

```
final int A = Integer.parseInt("1");
switch (value) {
case A: // 编译错误
break;
}
```

虽然 A 是 final ，但其值需要运行时计算，不是编译期常量。

**3.14.4 case 穿透**

```
switch (value) {
case 1:
System.out.println("A");
case 2:
System.out.println("B");
default:
System.out.println("C");
}
```

如果 value == 1 ，输出：

```
A
B
C
```

因为没有 break ，程序会继续执行后续分支。
有时穿透是有意使用：

```
switch (month) {
case 1:
case 3:
case 5:
case 7:
case 8:
case 10:
case 12:
days = 31;
break;
}
```

但现代 switch 表达式通常更清晰。

## 3.15 switch 表达式

现代 Java 支持箭头形式：

```
String result = switch (status) {
case 1 -> "待处理";
case 2 -> "处理中";
case 3 -> "已完成";
default -> "未知";
};
```

优点：

- 不需要 break
- 不会意外穿透
- 可以直接返回结果
- 编译器检查分支完整性
- 表达式更加简洁

**3.15.1 多标签合并**

```
int days = switch (month) {
case 1, 3, 5, 7, 8, 10, 12 -> 31;
case 4, 6, 9, 11 -> 30;
case 2 -> 28;
default -> throw new IllegalArgumentException("非法月份");
};
```

**3.15.2 使用 yield 返回值**

当分支需要多条语句时：

```
String result = switch (status) {
case 1 -> {
log.info("待处理状态");
yield "待处理";
}
case 2 -> {
log.info("处理中状态");
yield "处理中";
}
default -> "未知";
};
```

yield 用于从 switch 分支返回表达式结果。
它不是方法级别的 return 。

**3.15.3 枚举 switch**

```
String description = switch (status) {
case CREATED -> "已创建";
case PROCESSING -> "处理中";
case COMPLETED -> "已完成";
case CANCELED -> "已取消";
};
```

当枚举值全部覆盖时，可以不写 default 。
这样新增枚举常量后，编译器可能提示分支不完整，有利于代码演进。

## 3.16 for 循环

**3.16.1 基本结构**

```
for (初始化; 条件; 更新) {
// 循环体
}
```

示例：

```
for (int i = 0; i < 10; i++) {
System.out.println(i);
}
```

执行顺序：

```
初始化
↓
判断条件
↓
执行循环体
↓
执行更新表达式
↓
重新判断条件
```

初始化部分只执行一次。

**3.16.2 多变量控制**

```
for (int left = 0, right = array.length - 1;
left < right;
left++, right--) {
}
```

适合双指针场景，但不宜写得过于复杂。

**3.16.3 无限循环**

```
for (;;) {
}
```

与：

```
while (true) {
}
```

语义相近。

无限循环必须有明确退出机制，例如：

- break
- return
- 中断标志
- 外部状态变化

## 3.17 增强 for 循环

```
for (String value : list) {
System.out.println(value);
}
```

适用于：

- 数组
- 实现 Iterable 的对象
其核心目标是遍历元素，而不是控制索引。

**3.17.1 增强 for 不适合需要索引的场景**

错误做法：

```
int index = 0;
for (String value : list) {
process(index++, value);
}
```

如果索引本身具有业务意义，更适合普通 for 。

**3.17.2 增强 for 中修改变量不等于修改容器**

```
for (String value : list) {
value = value.trim();
}
```

这只是修改局部变量 value 的引用，不会替换列表中的元素。
如果要修改列表：

```
for (int i = 0; i < list.size(); i++) {
list.set(i, list.get(i).trim());
}
```

**3.17.3 遍历时删除元素**

```
for (String value : list) {
if (value.isEmpty()) {
list.remove(value);
}
}
```

通常会导致：

```
ConcurrentModificationException
```

正确方式之一：

```
Iterator<String> iterator = list.iterator();
while (iterator.hasNext()) {
String value = iterator.next();
if (value.isEmpty()) {
iterator.remove();
}
}
```

集合迭代器的具体机制放在集合章节。

## 3.18 while 与 do-while

**3.18.1 while**

```
while (condition) {
// 循环体
}
```

先判断条件，再执行循环体。
因此可能一次都不执行。

**3.18.2 do-while**

```
do {
// 循环体
} while (condition);
```

先执行一次，再判断条件。
因此至少执行一次。
注意结尾有分号：

```
while (condition);
```

**3.18.3 适用场景**

while 常用于：

- 不确定循环次数
- 按状态持续执行
- 读取流或消息
- 重试逻辑
- do-while 常用于：
- 菜单交互
- 至少执行一次的校验
- 首次执行后再判断是否继续

## 3.19 break、continue 与 return

**3.19.1 break**

break 用于终止：

- 当前循环
- 当前 switch

```
for (int value : values) {
if (value == target) {
break;
}
}
```

只退出最内层循环。

**3.19.2 continue**

continue 用于跳过当前循环剩余部分，进入下一轮：

```
for (String value : values) {
if (value == null) {
continue;
}
process(value);
}
```

适合用来减少嵌套。

**3.19.3 return**

return 用于结束整个方法：

```
public void execute(User user) {
if (user == null) {
return;
}
process(user);
}
```

有返回值的方法：

```
public int add(int a, int b) {
return a + b;
}
```

**3.19.4 三者区别**

关键字 影响范围
break 结束当前循环或 switch
continue 跳过当前轮循环
return 结束整个方法

## 3.20 标签语句

Java 支持标签：

```
outer:
for (int i = 0; i < 10; i++) {
for (int j = 0; j < 10; j++) {
if (condition) {
break outer;
}
}
}
```

可以直接退出外层循环。
也可以：

```
continue outer;
```

直接进入外层循环下一轮。

标签语句虽然合法，但应谨慎使用：

- 容易降低可读性
- 复杂控制流难维护
- 通常可以拆分方法或使用标志变量替代
适合保留为了解内容，不应作为常规写法。
