# 类型转换与精度陷阱

> **P1 · JDK 8+ · 5 分钟复习**

## 面试结论

表达式结果类型由语言转换规则决定，不由变量声明“感觉”决定。`byte`、`short`、`char` 参与多数算术运算时先提升为 `int`；整数溢出通常回绕而不是抛异常；二进制浮点不能精确表示所有十进制小数。

## 追问链

1. `byte + byte` 为什么是 `int`？二元数值提升的结果类型是 `int` 或更宽类型。
2. `+=` 为什么能编译而 `x = x + 1` 可能不能？复合赋值包含隐式窄化转换，仍可能产生溢出。
3. `int` 转 `float` 一定安全？不一定，合法宽化不等于精度完全保留。
4. 金额如何处理？用 `BigDecimal` 或最小货币单位整数，并明确 scale、舍入和比较语义。
