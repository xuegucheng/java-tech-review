# 对象模型与多态

> **P0 · JDK 8+；record/sealed/pattern matching 另标版本 · 5 分钟复习**

## 面试结论

编译时类型决定“能看到什么”和重载如何选择，运行时类型决定可重写实例方法的最终实现。字段、静态方法和普通重载不是同一套动态绑定规则。

## 30 秒回答

```text
引用的编译时类型
    → 成员可见性、重载候选
对象的运行时类型
    → 被重写实例方法的实现
```

向上转型隐藏具体类型，但不会改变对象；向下转型只是运行时检查，不会把对象变成另一个类型。面试回答应同时说清“变量类型”和“对象类型”，而不是只说“多态就是父类引用指向子类对象”。

## 追问链

1. 重载和重写有什么不同？重载通常在编译期按静态类型选，重写在运行时按动态类型分派。
2. 字段有多态吗？普通字段访问按声明类型解析，不像实例方法那样动态分派。
3. `static` 方法能重写吗？不能，子类同名方法属于隐藏；调用选择依赖声明类型。
4. 为什么接口适合依赖倒置？调用方依赖稳定能力契约，而不是依赖某个实现类。
5. 什么时候不用继承？当变化来自组合策略、生命周期或外部协作，而不是稳定的 is-a 契约时。

## 工程坑

- 在构造器中调用可重写方法，可能读到尚未初始化的子类状态。
- 用 `instanceof` 链不断增加分支，通常说明行为可以下沉到多态或策略对象。
- 为了“复用几行代码”继承具体类，会把父类变化传播给所有子类。
- `record` 和 `sealed` 是版本化能力，不应在 JDK 8+ 主线中不加标记地使用。

## 一句话复盘

> 静态类型决定调用边界，运行时类型决定重写实现；字段和静态方法不要套用实例多态结论。
